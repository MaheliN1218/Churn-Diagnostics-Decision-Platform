# Churn Diagnostics & Decision Platform

An end-to-end customer churn prediction and retention economics engine built with Streamlit, tree-based machine learning classifiers, and SHAP explainability.

## Key Features

* **Profit Optimization Curve:** Dynamically optimizes decision cutoffs by balancing Customer Lifetime Value (LTV) against incentive intervention costs.
* **Account Risk Diagnostics:** Real-time single-account risk scoring with waterfall SHAP feature attribution.
* **Demographics & Cohort Analysis:** Population distribution breakdowns across contract types, tenure brackets, and billing methods.
* **Batch Campaign Scoring:** Bulk upload and automated risk-tier allocation with prescribed retention offers.

## Tech Stack

* **Frontend:** Streamlit
* **Modeling & Explainability:** Scikit-Learn, SHAP, Matplotlib
* **Data Processing:** Pandas, NumPy
